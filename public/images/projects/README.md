# Project images

One image per project. Filenames are referenced from `data/images.ts`:

- `asvab-tutoring-site.webp` (real screenshot)
- `netbazar-dashboard.webp` (real screenshot)
- `seo-analytics-demo.jpg` (royalty-free Unsplash placeholder; replace with a
  real SEO report screenshot when one exists)

Recommended: capture only the first screen (above the fold) of the live site at
1440px wide, export at about 1600x1000 (16:10) as JPG (~80 quality) or WebP,
under 300 KB each. Full-page captures become unreadable strips in the cards.
